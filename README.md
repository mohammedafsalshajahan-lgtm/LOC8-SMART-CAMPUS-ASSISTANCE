# LOC8-SMART-CAMPUS-ASSISTANCE
Java based smart campus assistance platform using OOP and Java Swing
LOC8 – Smart Campus Assistance Platform

Project Overview

LOC8 is a Java-based desktop application designed to make campus information and assistance easily accessible to students, faculty members, staff, and visitors.

The application combines three major modules into one platform.

Main Modules

1. Lost & Found Management

- Report lost and found items.
- Add item details and supporting images.
- Search and browse reported items.
- Mark items as recovered.

2. Smart Campus Search

- Search for campus locations.
- Find departments, classrooms, laboratories, libraries, hostels, offices, and other facilities.
- View location details.

3. Emergency Contacts

- Search campus emergency contacts.
- Access important national emergency numbers.

Technologies Used

- Java 17+
- Java Swing
- Object-Oriented Programming (OOP)
- File Handling
- CSV and Java Serialization

System Requirements

- Java Development Kit (JDK) 17 or later.
- Windows, Linux, or macOS.
- Java-compatible development environment (optional).

Project Structure

- "src/" – Java source code.
- "data/" – Local application data.
- "README.md" – Project documentation.
- "run-windows.bat" – Windows launch script.
- "run-linux-mac.sh" – Linux/macOS launch script.

How to Run

Extract the project ZIP file, open a terminal in the project folder, compile the Java source files, and run "loc8.LOC8App".

Detailed instructions are included in the project ZIP.

Project Scope

LOC8 is designed as a standalone desktop application. It uses local file storage and does not require an internet connection or a central server.

Note

This repository contains the project report and Java application source package. Campus-specific information and emergency contact numbers should be verified and updated before real-world use.
